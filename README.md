# Lumen — восстановленный проект

Исходники восстановлены из `lumen-kvm.jar` для Minecraft 1.21.4 / Fabric.

- Расшифрованы все 715 классов проекта.
- Получено 516 Java-файлов с Yarn-именами Minecraft API.
- 7744 обфусцированных Unicode-имени заменены на `recoveredField*` и `recoveredMethod*`.
- Ресурсы и вложенные зависимости сохранены из исходного JAR.
- `libs/lumen-shaded-dependencies.jar` содержит только сторонние бинарные зависимости, не код `dlc.lumen`.

Это декомпиляция, а не утраченные оригиналы один в один. Комментарии, исходные локальные имена и часть названий членов класса восстановить невозможно. Перед дальнейшей разработкой имеет смысл вручную переименовывать `recovered*` по смыслу.

Для сборки нужны JDK 21 и Gradle 8.x. Базовая команда: `gradle build`.

## Как работать вдвоём

- Запуск у второго разработчика: двойной клик по `play.bat` — он сам скачивает свежие изменения с GitHub и запускает Minecraft.
- Свои изменения отправлять: `git add -A` → `git commit -m "что изменил"` → `git push`.
- Чужие изменения получить: `git pull` (или просто перезапустить `play.bat`).
- Перед началом работы всегда делай `git pull`, чтобы не было конфликтов.
- Если git пишет про конфликт — не паникуй: `git stash`, потом `git pull`, потом `git stash pop`.

`runtime-resources` хранит только специфичные для Lumen runtime-файлы отдельно от `src`. Vosk 0.3.45, ONNX Runtime 1.18.0 и JNA 5.15.0 автоматически загружаются из Maven Central перед первым `runClient`/`build`, сохраняются в кэше Gradle и добавляются в dev-ресурсы и обычный mod JAR. Для первого запуска нужен интернет; следующие запуски работают из кэша. `sourcesJar` runtime-файлы не включает.
